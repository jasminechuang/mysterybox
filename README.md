# 廢土荒謬傭兵盲盒：末日生存轉蛋所

歡迎來到《廢土荒謬傭兵盲盒：末日生存轉蛋所》！這是一個充滿末日荒謬風格的網頁小遊戲與轉蛋系統。

## 遊戲特色

* **生存天數追蹤**：記錄你在廢土中艱苦求生的天數（目前為生存第 2 天）。
* **物資補給箱**：每天登入開啟每日補給箱，獲得生存物資、金屬廢料與珍貴的轉蛋券。
* **荒謬轉蛋**：消耗轉蛋券來抽取各式各樣奇葩又有趣的廢土傭兵。
* **傭兵圖鑑**：收集並解鎖你抽到的所有荒謬傭兵。
